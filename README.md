# 修仙 · 引气入门

Minecraft Java 1.20.1 / Forge，模组 ID `xiuxian`。开发基线 Forge 47.3.0，用户试玩环境为 Forge 47.4.28。

## 图文入门书

每名玩家首次进入世界时获得《引气入门》。原有书本仍可右键打开新版双页图文界面。目录和草药图标可点击，左右箭头翻页，底部“目录”返回总览，Esc 或右上角关闭。

书中包含 8 种草药的放大物品图样、环境、辨识和用途，以及药炉合成、药草种植和炼药图示。使用本模组自己的贴图与书页背景。所有教程保留在书里，物品与药炉不增加悬浮引导。

遗失可输入 `/xiuxian guide` 补领，无需管理员权限。背包满时书掉在玩家身边，重登不会重复发放。`giveGuideOnFirstJoin=true` 控制首次发书，可在世界的 `serverconfig/xiuxian-server.toml` 中关闭。图文界面中的成功率读取当前已同步的世界配置。

## 八类草药

| 环境 | 草药 | 对应药液 |
|---|---|---|
| 平原、向日葵平原、草甸 | 引气草 | 引气药液 |
| 森林与未积雪的针叶林 | 青木芝 | 青木药液 |
| 雪原、雪林、积雪山坡等 | 凝霜草 | 凝霜药液 |
| 各类山峰与风袭山地 | 石髓花 | 石髓药液 |
| 沙漠、恶地、热带草原 | 赤阳草 | 赤阳药液 |
| 丛林、沼泽、蘑菇岛 | 泽兰草 | 泽兰药液 |
| 河岸、海滩、石岸、海岛陆地 | 碧潮草 | 碧潮药液 |
| 繁茂洞穴、溶洞、深暗之域 | 幽光苔 | 幽光药液 |

环境配置覆盖主世界 53 种生物群系，各群系只归入一种草药类别。草药在新生成区块中概率生成，碧潮草长在岸上和岛屿陆地，幽光苔在地下生成并提供微弱光照。旧区块已有药草保留，需去新生成的区块找新增药草。

左键破坏整株获取，各生长阶段均可采集。对空长按使用键食用，对地面右键种植。8 种均可种在泥土、草方块等土壤上，还支持各自环境的雪块、岩石、沙地或泥地。幽光苔无需日光，其余需充足光照生长。

8 种药草入门成功率相同，默认 25%。任意一种都能和水瓶在基础炼药炉中炼成它自己的药液，药液默认成功率 75%。原有引气草和药液物品 ID 不变，旧草叶仍映射为引气草。

## 炼药和修炼

药炉工作台配方，C 为圆石，F 为营火。

```text
C C
C C
CFC
```

左槽放 1 株任意入门草药，中槽放 1 个原版水瓶，10 秒得到 1 瓶对应药液。无需额外燃料，成品槽满时暂停。玻璃瓶对水使用即可获得水瓶。

饱食时也可服用。失败只消耗当次物品，药液返还空瓶；成功进入炼气一层，按 K 查看。已入门不重复消耗入门药物。创造模式不消耗物品，也不额外生成空瓶。

概率配置保留旧键 `leafChance=0.25`（整株药草）及 `liquidChance=0.75`。退出世界后修改配置。JEI 可选，已注册 8 条药液配方；对草药按 U 或对药液按 R 查询。

## 炼气进度与真实属性

引气入体后自动吐纳，在线、存活且非旁观模式时每 20 个游戏 tick 获得修为。走路、建设和战斗时也会持续积累。默认每秒 1 点，本次试用将升级难度系数设为 10，一层升二层需要 3000 点；之后每层需求为 `300 × 10 × 当前层数`。修为足够自动升层，多余进度保留，九层为炼气圆满。离线与死亡期间不积累。

K 面板显示当前层数、修为数值、百分比进度条、当前/最大生命、攻击力和吐纳状态。攻击力由服务器直接同步，包含手持武器的属性值。普通无护甲目标的满蓄力空手攻击，默认一层为 2 点、二层为 3 点；护甲、暴击与蓄力仍按原版结算。2 点生命等于 1 颗心。

| 境界 | 最大生命 | 空手攻击属性 |
|---|---:|---:|
| 凡人 | 20 | 1 |
| 炼气一层 | 22 | 2 |
| 炼气二层 | 24 | 3 |
| 炼气九层 | 38 | 10 |

每层默认增加 2 点最大生命和 1 点攻击。使用固定 UUID 的原版属性修饰器，不覆盖玩家原本的基础值；重登、换维度和死亡重生时恢复，不重复叠加。升级会填充新增的生命容量，不会把原有伤势直接治满。境界和修为保存于玩家数据，旧存档只有“已引气入体”标记时迁移为一层、修为 0。

以下配置位于世界的 `serverconfig/xiuxian-server.toml`，退出世界后修改：

```toml
automaticCultivation = true
cultivationPerSecond = 1
baseProgressPerLevel = 300
cultivationDifficultyMultiplier = 10
healthPerLevel = 2.0
attackDamagePerLevel = 1.0
```

可用 `scripts/test-progression.ps1` 执行不启动游戏的升级规则测试。游戏引擎属性检查在 `CultivationAttributeGameTests` 中，客户端仍由用户自行试玩。
## 功法、灵食、丹药与灵石

这批试用数值集中在世界的 `serverconfig/xiuxian-server.toml`。新增难度系数默认 10，已有 `baseProgressPerLevel=300` 的世界也会按 3000 起步；已获得的层数和修为保留。纯基础吐纳从一层到九层共需约 30 个在线小时，功法、灵食和消耗品会缩短。最终平衡仍需玩家试玩调整。

| 资源 | 试用作用 | 获取 |
|---|---|---|
| 一、二、三阶基础吐纳诀 | 1.25 / 1.5 / 2 倍基础速度 | 工作台制作，JEI 查看配方 |
| 灵草膳 | 300 秒内再乘 1.5，不叠加强度，重复吃刷新时长 | 任意入门草药＋小麦＋苹果＋碗 |
| 聚气丹 | 直接加 100 修为 | 药炉：任意草药＋普通灵石，10 秒 |
| 灵石 | 对空气右键，直接加 20 修为 | 石镐或更好工具开采灵石矿 |
| 二阶灵石 | 对空气右键，直接加 180 修为 | 9 个灵石在工作台合成 |

功法右键学习并消耗书，保留最高阶，低阶或同阶不消耗；死亡重登保留。灵食饱食时也可吃，返还碗，效果随在线游戏时间流逝，死亡时按原版清除。功法与灵食相乘，小数修为会保存累计。K 面板展示当前功法、实际吐纳速度与滋养剩余时间。初始引气药液仍只负责入门，聚气丹和灵石用于已入门玩家；九层圆满后不再消耗这些成长道具。

灵石矿与深层灵石矿为灰色岩石内的白色晶簇和细裂纹。普通挖掘固定直接掉 1 个灵石，无需烧炼；精准采集保留矿石方块。主世界 Y=-48 至 48 概率生成：零散矿每团 1～2 块，小灵脉目标 12～16、中灵脉 32～48、大灵脉 64～96。灵脉以连接矿团表示，遇到洞穴、非岩石或区块写入边界时实际数量可能较少。大小灵脉依次更稀有，已生成区块不会补矿。

灵脉核心的地表加速与矿石再生已实现，详见下方灵脉章节。

```toml
manualTier1Multiplier = 1.25
manualTier2Multiplier = 1.5
manualTier3Multiplier = 2.0
spiritFoodMultiplier = 1.5
spiritFoodDurationSeconds = 300
spiritStoneProgress = 20
tier2SpiritStoneProgress = 180
qiGatheringPillProgress = 100
```

书底部“资源”入口包含功法、灵食、丹药、灵石与灵脉章节；原版工作台配方和药炉 JEI 配方均已更新。灵石压缩仅开放一阶到二阶。
## 构建与检查

```powershell
.\build.ps1 build
node scripts/generate-resources.cjs
node scripts/validate-content.cjs
```

Java 17 位于项目 `.tools/jdk-17...`，工具、缓存和产物均在 E 盘。成品为 `build/libs/xiuxian-0.1.0.jar`。JEI 15.74.0.233 仅作可选 API 编译引用，不随包分发。

用户自行进行客户端试玩，独立服和双人联机验收后续进行。实际检查记录见 `VALIDATION.md`。源码含炉子与玩家属性的 GameTest，具体执行结果见验证记录。原创部分暂保留所有权利，Forge MDK 许可见 `LICENSE.txt`。



## 灵脉核心与地表寻脉

新生成的小、中、大灵脉带有星纹核心。默认水平半径分别为16、32、48格，中心倍率为1.25、1.5、2倍，按水平距离线性衰减。上界使用生成时核心柱的自然地表高度加16格，下界为核心高度。多个灵脉取最高倍率，再与功法、灵食相乘，K面板显示结算结果。

保留核心时，正确工具开采绑定矿石会留下枯竭矿。枯竭矿所在区块加载累计1800秒恢复。精准采集取走矿石，挖掉枯竭矿清理该位置，破坏核心停止加速与再生。普通散矿仍是一次性资源。核心不掉落，玩家放置的矿石没有再生绑定。

服务端配置增加 smallVeinRadius、mediumVeinRadius、largeVeinRadius，smallVeinMultiplier、mediumVeinMultiplier、largeVeinMultiplier，以及 veinRegenerationSeconds。旧存档已经探索的区块不会补生成核心。

当前功能与待验收事项见 [开发进度](DEVELOPMENT.md)。每完成开发任务同步维护该文档。


## 炼药与炼丹（2026-11-03）

本节更新前面旧版药炉炼制聚气丹的说明。聚气丹现迁入基础炼丹炉，药炉仅炼药液。

- 药炉新增辅药槽，主药和水瓶槽、成品槽保留旧编号。青木芝＋小麦＋水瓶炼回春药液，凝霜草＋泽兰草＋水瓶炼清宁药液，引气草＋青木芝＋水瓶炼温养药液。各材料1份、10秒1瓶。错误辅药不会退回引气配方。无辅药仍制作八种对应引气药液。
- 回春药液8秒恢复4点生命，回春丹8秒恢复8点。清宁药液解毒，清灵丹额外抗毒3分钟。温养药液3分钟吐纳×1.15，养气丹5分钟×1.35，取最高有效倍率，再与功法、灵食、灵脉相乘。药液喝完返还空瓶。
- 灵铜锭由铜锭＋普通灵石合成。药炉配方加顶部灵石。丹炉中心熔炉、顶部灵石，其余7格灵铜锭。
- 聚气丹丹方用纸、墨囊、灵石合成。其他三丹方来自地牢和废弃矿井宝箱，每箱15%机会随机抽一张。丹方加纸和墨囊抄录，消耗一张原件输出两张，总量增加一张。
- 丹炉放丹方、主药、辅药、灵石、煤或木炭。聚气丹主药任意一种入门草药3＋小麦1＋灵石1；回春丹青木芝3＋石髓花1＋灵石1；清灵丹凝霜草2＋泽兰草2＋灵石1；养气丹引气草3＋青木芝2＋灵石2。
- 炼气期可开炉，30秒一炉，开炉扣材料和1燃料、保留丹方并保存本炉目标与成功率。关闭界面后继续，区块卸载暂停。默认60%成功产1丹，否则产1丹渣，丹渣暂无用途。
- 配置 alchemyBaseChance=0.6、alchemyRealmBonus=0.15、alchemyFurnaceBonus=0.15、alchemyChanceCap=0.95。概率函数支持大境界/丹炉阶级加成，当前游戏可用组合是炼气期与一阶炉。筑基和二阶炉属于后续内容。

游戏模型按设计图的石质开口药炉和铜色三足带盖丹炉制作，物品为低分辨率像素版本。JEI分别展示药液和丹药配方、丹方与数量，书中更新操作流程。
